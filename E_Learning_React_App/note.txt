            }
        };

        fetchFunFacts();

4. Chỉnh sửa lại code dropdown của header 

    Chỉnh link lại
    -to="something" (không có /) → Relative path -> Nếu bạn đang ở /home, thì to="course/search" sẽ thành /home/course/search (không đúng).
    to="/something" (có /) → Absolute path -> Dùng to="/course/search" thì luôn đúng, vì nó luôn dẫn về gốc /.
