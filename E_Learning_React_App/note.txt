    -Ví dụ Cha là Home chứa _.module.scss  con sẽ không bị ảnh hưởng

3. Chỉnh sửa lại code dropdown của header 

    Chỉnh link lại
    -to="something" (không có /) → Relative path -> Nếu bạn đang ở /home, thì to="course/search" sẽ thành /home/course/search (không đúng).
    to="/something" (có /) → Absolute path -> Dùng to="/course/search" thì luôn đúng, vì nó luôn dẫn về gốc /.

9. Thư mục /services

    Thực hiện call api 
    - Tăng khả năng tái sử dụng code
    - Dễ gỡ đổi và tái cấu hình
    - Phân tách call API và logic UI

    Bình thường mình sẽ Call API trực tiếp
    - Viết hàm
    - Gọi tại API tại Component luôn
    
    export const search = async (q, type = 'less') => {
        try {
            const res = await httpRequest.get('users/search', {
                params: {
                    q,
                    type,
                },
            });
            return res.data;
        } catch (error) {
            console.log(error);
        }
    };
